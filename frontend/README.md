# NirmanSetu frontend

The UI was imported from
[siddhi170407/nirmansetu-infrastructure-hub](https://github.com/siddhi170407/nirmansetu-infrastructure-hub)
at commit `593e94680938ea47b61f23eea0fcdd14b3e77cd3`.

The original React components, dashboard, project list/details, milestones,
inspections, payments, documents, analytics, audit trail, login screen, styles,
responsive sidebar, fonts, public assets, and sample data are retained.

## Integration

This frontend runs as a Vite single-page application alongside the existing
Django backend. The source used TanStack Start; its server entry points and
Lovable/Cloudflare build wrapper were replaced with a standard Vite entry point
and the [TanStack Router Vite plugin](https://tanstack.com/router/latest/docs/installation/with-vite).
The page components still use TanStack's original file-based routing.

- `src/main.tsx` mounts the router and imports the original stylesheet.
- `src/routes/__root.tsx` retains the shared providers, metadata, fonts, and
  error/not-found screens; `index.html` supplies the browser document shell.
- `src/router.tsx` registers the router's TypeScript type.
- `src/routeTree.gen.ts` is generated by the router plugin during dev/build.
- `vite.config.ts` preserves the main project's port 5173 and `/api` proxy.
- `package-lock.json` records npm dependencies. The source's Bun lockfile,
  Lovable editor metadata, Git metadata, and server-only modules were not imported.

The login and role selector are **UI demonstrations**, not authentication or
authorization. The existing sample data in `src/lib/data.ts` has not been replaced
with Django calls. Buttons without handlers in the source remain UI placeholders.
The source's security/compliance text is presentation copy, not a verified claim.

## Integration validation

- Production build: passed with Vite 8.3.6, producing `dist/`.
- TypeScript check: passed.
- Route tests: all 10 passed, including the dynamic project detail route.
- Browser: dashboard, project details, charts, and mobile navigation verified.
  The mobile layout was checked at 390 px; no page overflow or browser errors
  were observed in these checks.
- Source fidelity: 65 original UI/component, stylesheet, sample-data, and public
  asset files match the cloned source byte-for-byte.
- Backend files and the main repository's remote are unchanged.

The source's lint configuration reports 5,454 Prettier formatting errors and
7 Fast Refresh export warnings in the unchanged imported files. The adapted
entry point, router root, Vite/Vitest configs, and routing tests pass lint.
The imported UI was not reformatted wholesale as part of this integration.

The npm audit reports 8 dependency findings: 7 moderate findings in the
TypeScript ESLint/minimatch dependency chain, and 1 high finding in Zod 3.
Vite uses the main project's newer version range rather than the source's
8.1.5 pin, resolving the source's Vite finding. The remaining suggested fixes
include changes outside the imported dependency ranges and have not been forced.
These findings do not prevent the frontend build, but remain dependency
maintenance work before deployment.

## Run locally

From this directory, with Node.js 22.12+ or 24:

```powershell
npm.cmd ci
npm.cmd run dev
```

Open <http://127.0.0.1:5173>. Leave the terminal running; stopping Vite makes the
local URL unavailable. The imported demo pages do not require PostgreSQL or the
Django server. `/api` requests require Django on port 8000. Copy `.env.example`
to `.env` only if you need to customize the proxy or future API base path.

If npm reports `UNABLE_TO_VERIFY_LEAF_SIGNATURE` on this Windows machine, set
`$env:NODE_USE_SYSTEM_CA = '1'` in the same terminal and retry. This keeps TLS
verification enabled. On macOS/Linux, use `npm` instead of `npm.cmd`.

## Checks and production output

```powershell
npm.cmd run build
npm.cmd test
npm.cmd run typecheck
npm.cmd run lint
```

`npm.cmd run preview` serves the build in `dist/`. Production hosting must send
frontend routes such as `/projects/NS-RD-0142` to `index.html` for client-side routing,
while forwarding `/api/` to Django. The Vite development proxy is not part of the
static production build. Google Fonts requires internet access; the source's
system-font fallbacks remain available offline.
